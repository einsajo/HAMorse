Constraint: Stack is React, TypeScript, Vite, and plain CSS. No external 3D libraries. All audio must be generated dynamically using the Web Audio API (`OscillatorNode` for 700Hz Morse tones, `BufferSource` or custom processors for background static). Do not use the Web Speech API. To comply with strict mobile browser auto-play policies, the `AudioContext` must remain completely suspended until the user explicitly interacts with the physical "Main Power" toggle switch on the UI.
